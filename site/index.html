添加容易，管理也要说清楚。

订阅是只读的。你可以单独设置颜色、隐藏频道，或随时取消订阅。

  1. 1点击频道的“添加”后，确认打开日历。
  2. 2也可在“日历 → 添加日历 → 添加订阅日历”粘贴 HTTPS 地址。
  3. 3取消时进入“日历 → ⓘ → 取消订阅”。
  1. 1日历菜单选择“文件 → 新建日历订阅”。
  2. 2粘贴 HTTPS 地址，并选择刷新频率与颜色。
  3. 3取消时在左侧日历列表右键选择“取消订阅”。
